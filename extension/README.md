# Odyssey Companion • Chromium Extension

> **The 1-Click Instapaper / Pocket Companion for Odysseus.**  
> Purify any article, strip author bios and web noise, and save clean narrative text to your Odysseus reading chamber with a single click.

---

## ✦ Features

- **1-Click Save**: Click the Odyssey toolbar icon to instantly purify and archive the current webpage into your Odysseus Salon.
- **Read in Zen Chamber**: Open any web article directly in the Odysseus distraction-free reading chamber with your tactile progress scroll wheel.
- **Right-Click Context Menu**:
  - `✦ Save Story to Odysseus Salon`
  - `✦ Read Now in Zen Chamber ↗`
  - `✦ Save Highlight to Odysseus Notebook` (on selected text)
- **In-Page Luxury Toast**: Confirms saves on the page with a direct link to commence reading.
- **Keyboard Shortcuts**:
  - <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> (<kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> on Mac) to quick-save without opening the popup.
  - <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> to open the popup.
- **Offline Cache**: Keeps recent saves locally and syncs to your Odysseus backend.

---

## 🚀 How to Install in 10 Seconds (Chrome, Brave, Arc, Edge)

1. Open **Google Chrome** (or Arc / Brave / Edge).
2. Navigate to `chrome://extensions/` in your address bar.
3. Enable **Developer mode** (toggle in the top-right corner).
4. Click **Load unpacked** in the top-left corner.
5. Select the `extension/` folder inside this Odysseus repository:
   ```
   /Users/shubhamupadhyay/Documents/Projects/Odysseus/extension
   ```
6. **Done!** The orange Odysseus compass icon `✦` will appear in your browser extensions bar. Click the pin icon to keep it visible on your toolbar!

## ⚙️ Configuration

By default, Odyssey connects to the official deployed Odysseus salon:
`https://odysseus.vercel.app`

If you are developing locally:
1. Right-click the Odyssey icon in your toolbar and select **Options**.
2. Change the URL to `http://localhost:3000` (or click the **Local Dev** preset button).
3. Click **Save URL**.
